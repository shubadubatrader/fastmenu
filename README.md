# Тарелка

Адаптивное веб-приложение для планирования простого сбалансированного меню на неделю по принципу Гарвардской тарелки.

## Возможности

- профиль каждого члена семьи: возраст, пол и вес;
- настройка активности, стиля готовки и меню без мяса;
- меню на 7 дней с быстрыми заменами блюд;
- расчёт семейных порций;
- автоматический список покупок по категориям;
- отметки купленных продуктов, копирование и печать списка;
- сохранение плана в браузере;
- адаптивный интерфейс для телефона, планшета и компьютера.
- установка на домашний экран как PWA и базовая работа офлайн.

## Запуск

Это статическое приложение без сборки. Откройте `dist/index.html` или запустите локальный HTTP-сервер из корня проекта:

```bash
python -m http.server 4173 --directory dist
```

Затем откройте `http://localhost:4173`.

## GitHub Pages и установка на телефон

В настройках репозитория выберите **Pages → GitHub Actions** либо опубликуйте содержимое папки `dist`. После публикации откройте сайт на телефоне и выберите «Добавить на главный экран» / «Установить приложение». HTTPS на GitHub Pages подходит для service worker и PWA.

## Важно

Расчёт порций ориентировочный. Приложение не заменяет консультацию врача или диетолога, особенно при заболеваниях, беременности, аллергиях и лечебных диетах.
