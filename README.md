# Тарелка

Адаптивное веб-приложение для планирования простого сбалансированного меню на неделю по принципу Гарвардской тарелки.

## Возможности

- профиль каждого члена семьи: возраст, пол, рост и вес;
- настройка активности, стиля готовки и меню без мяса;
- автоматический и ручной режим планирования;
- меню на 7 дней с рецептами и быстрыми заменами блюд;
- отдельная фотография для каждого блюда;
- расчёт семейных порций;
- автоматический список покупок по категориям;
- отметки купленных продуктов, копирование и печать списка;
- планы с датой недели, история и локальное сохранение на устройстве;
- адаптивный интерфейс для телефона, планшета и компьютера.
- установка на домашний экран как PWA и базовая работа офлайн.

## Запуск

Это статическое приложение без сборки. Откройте `dist/index.html` или запустите локальный HTTP-сервер из корня проекта:

```bash
python -m http.server 4173 --directory dist
```

Затем откройте `http://localhost:4173`.

## Методика расчёта

### 1. Оценка энергии

Приложение использует уравнения Estimated Energy Requirement (EER) из отчёта National Academies *Dietary Reference Intakes for Energy* (2023). Это оценка средней суточной потребности для поддержания веса, а не медицинское назначение.

Общая форма уравнения:

```text
EER = C₀ + Cвозраст × возраст + Cрост × рост_см + Cвес × вес_кг
```

Коэффициенты выбираются отдельно по полу, возрастной группе и активности:

| Группа | Активность | C₀ | Cвозраст | Cрост | Cвес |
|---|---:|---:|---:|---:|---:|
| Женщины 19+ | малоподвижная | 584.90 | −7.01 | 5.72 | 11.71 |
| Женщины 19+ | умеренная | 575.77 | −7.01 | 6.60 | 12.14 |
| Женщины 19+ | активная | 710.25 | −7.01 | 6.54 | 12.34 |
| Мужчины 19+ | малоподвижная | 753.07 | −10.83 | 6.50 | 14.10 |
| Мужчины 19+ | умеренная | 581.47 | −10.83 | 8.30 | 14.94 |
| Мужчины 19+ | активная | 1004.82 | −10.83 | 6.52 | 15.91 |
| Девочки 3–18 | малоподвижная | 55.59 | −22.25 | 8.43 | 17.07 |
| Девочки 3–18 | умеренная | −297.54 | −22.25 | 12.77 | 14.73 |
| Девочки 3–18 | активная | −189.55 | −22.25 | 11.74 | 18.34 |
| Мальчики 3–18 | малоподвижная | −447.51 | 3.68 | 13.01 | 13.15 |
| Мальчики 3–18 | умеренная | 19.12 | 3.68 | 8.62 | 20.28 |
| Мальчики 3–18 | активная | −388.19 | 3.68 | 12.66 | 20.46 |

Расчёт ограничен техническим диапазоном 900–4500 ккал/день для защиты от ошибочного ввода. Подробности и исходные таблицы: [National Academies / NCBI](https://www.ncbi.nlm.nih.gov/books/NBK591020/).

### 2. Переход к порциям

Базовые количества в каталоге заданы на условную порцию рациона около 2200 ккал:

```text
индивидуальный коэффициент = EER / 2200
```

Коэффициент ограничивается диапазоном 0,5–1,8. Коэффициенты всех членов семьи складываются. Полученный семейный коэффициент умножается на количество каждого ингредиента.

Это масштабирование списка продуктов, а не точный подсчёт калорий конкретной тарелки: для клинической точности понадобились бы проверенная нутриционная база каждого продукта, индивидуальные цели и наблюдение динамики веса.

### 3. Принцип тарелки

Обеды и ужины составляются по визуальному принципу Harvard Healthy Eating Plate:

- около ½ блюда — разные овощи и часть фруктов;
- около ¼ — цельнозерновой гарнир;
- около ¼ — полезный источник белка;
- преимущественно растительные масла и вода вместо сладких напитков.

Сам принцип тарелки не задаёт калории или абсолютный размер порции. Источник: [Harvard T.H. Chan School of Public Health](https://nutritionsource.hsph.harvard.edu/healthy-eating-plate/).

## Подбор и чередование блюд

Каждое блюдо размечено компонентами: `proteinKey` (курица, индейка, рыба, яйца, бобовые, тофу) и `sideKey` (рис, гречка, булгур, киноа, паста и т. п.).

В автоматическом режиме:

1. Выбирается каталог с мясом или вегетарианский подкаталог.
2. Четырнадцать обедов и ужинов берутся из последовательности различных комбинаций белка, гарнира и овощей.
3. Пока каталог не исчерпан, точное блюдо не повторяется.
4. При небольшом вегетарианском каталоге повторение возможно только после полного прохода списка.
5. Завтраки повторяются не раньше, чем пройдены все пять вариантов.
6. Кнопка замены выбирает следующий допустимый вариант и сразу пересчитывает покупки.

В ручном режиме пользователь выбирает завтрак, обед и ужин для каждого дня самостоятельно. Список покупок строится тем же способом.

## Список покупок

Все одинаковые ингредиенты из 21 приёма пищи объединяются по названию и единице измерения. Количество умножается на сумму семейных коэффициентов. Штучные продукты округляются вверх до целого, граммы и миллилитры — вверх до 50. После этого позиции группируются по отделам магазина.

## Локальное хранение

Текущий план автоматически хранится в `localStorage`. Кнопка «Сохранить неделю» создаёт именованный снимок с датой начала недели, датой создания, людьми, настройками, блюдами и отмеченными покупками. Сохраняется до 12 последних недель. Данные остаются только в текущем браузере и не синхронизируются между устройствами; очистка данных браузера удалит планы.

## Фотографии

Для каждого блюда используется отдельная AI-сгенерированная фотография, созданная по его фактическому набору белка, гарнира и овощей. Изображения оптимизированы в WebP и кешируются PWA для офлайн-просмотра.

## GitHub Pages и установка на телефон

В настройках репозитория выберите **Pages → GitHub Actions** либо опубликуйте содержимое папки `dist`. После публикации откройте сайт на телефоне и выберите «Добавить на главный экран» / «Установить приложение». HTTPS на GitHub Pages подходит для service worker и PWA.

## Важно

Расчёт порций ориентировочный. Приложение не заменяет консультацию врача или диетолога, особенно при заболеваниях, беременности, аллергиях и лечебных диетах.
